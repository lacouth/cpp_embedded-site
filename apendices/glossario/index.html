    Glossário¶

    Os termos aparecem na ordem do curso. O capítulo onde cada um é explicado está entre parênteses.

    Termo O que é
    microcontrolador um chip com processador, memória e periféricos (pinos, timers, comunicação) juntos. O ESP32 é um. (cap. 1)
    GPIO General Purpose Input/Output: um pino que o programa configura como entrada ou saída digital. (cap. 1)
    setup() / loop() as duas funções de um sketch: setup() roda uma vez, loop() é chamado para sempre. (cap. 1)
    sketch o programa principal de um projeto Arduino (sketch.ino no Wokwi). (cap. 1)
    HIGH / LOW os dois níveis de um pino digital: 3,3 V e 0 V no ESP32. (cap. 1)
    inicia() a convenção do curso (o begin() do mundo Arduino): o método que mexe no hardware, chamado no setup(). (cap. 1)
    Arduino falso o arduino_falso.h: funções com os nomes do Arduino que só guardam valores, para testar classes sem placa. (cap. 1)
    padrão de projeto solução conhecida, com nome, para um problema de projeto que se repete. A classe Led já é um (Hardware Proxy). (cap. 1)
    Hardware Proxy padrão em que um objeto fica no lugar do periférico e é o único a falar com ele; o resto do programa só chama métodos como liga(). (cap. 1; volta no cap. 6)
    inicialização em duas fases o construtor só guarda a configuração e um segundo método (inicia()) mexe no hardware, porque objetos globais nascem antes do setup(). (cap. 1)
    invariante o que precisa ser verdade sobre um objeto o tempo todo. A classe existe para protegê-lo. (cap. 2)
    pull-up interno resistor dentro do chip que mantém um pino de entrada em HIGH quando nada o puxa para baixo. (cap. 2)
    borda de subida o instante em que um sinal passa de "não" para "sim" (botão: de solto para apertado). (cap. 2)
    bounce (quique) as oscilações rápidas de um contato mecânico ao ser apertado ou solto. (cap. 2)
    millis() milissegundos desde que a placa ligou, como unsigned long. (cap. 3)
    bloquear parar o programa esperando algo (como delay() faz), sem atender mais nada. (cap. 3)
    composição uma classe que tem objetos de outras classes como campos. (cap. 3)
    superloop o loop() como lista de atualiza() que nunca esperam, cada objeto cuidando do próprio tempo. (cap. 3)
    Polling padrão em que o programa pergunta o estado de algo a cada volta, em vez de ser avisado quando ele muda. (cap. 3; comparado com interrupção no cap. 9)
    máquina de estados modelo em que o sistema está em um estado de cada vez e muda por transições disparadas por eventos ou condições. (cap. 4)
    debounce filtrar o quique: só aceitar uma leitura que fica estável por um tempo. (cap. 4)
    tipo de largura fixa uint8_t, int16_t, uint32_t…: inteiros com o mesmo número de bits em qualquer plataforma (<cstdint>). (cap. 5)
    registrador uma palavra do chip, num endereço fixo, em que cada bit ou grupo de bits configura ou mostra o estado de um periférico. (cap. 5)
    máscara um número com 1 nos bits que interessam, usado com as operações E, OU e OU exclusivo bit a bit para ler, ligar, desligar ou inverter só esses bits. (cap. 5)
    campo de bits um grupo de bits vizinhos de um registrador que guarda um número (um divisor, um modo). (cap. 5)
    static_assert uma condição conferida pelo compilador: se for falsa, o programa não compila. (cap. 5)
    volatile avisa o compilador que aquela memória pode mudar ou ser lida por fora do programa: cada leitura e cada escrita tem que acontecer de verdade. (cap. 6)
    W1TS / W1TC registradores do ESP32 em que escrever 1 num bit liga (write 1 to set) ou desliga (write 1 to clear) só aquele pino. (cap. 6)
    micros() microssegundos desde que a placa ligou; dá a volta a cada ~71 minutos. (cap. 6)
    jitter a variação do tempo de uma operação que deveria levar sempre o mesmo tempo. (cap. 6)
    ADC conversor analógico-digital: transforma uma tensão num número. No ESP32, 0 a 4095 (12 bits). (cap. 7)
    atenuação o ajuste do ADC do ESP32 que define até que tensão ele mede; o padrão, ADC_11db, vai até perto de 3,3 V. (cap. 7)
    PWM modulação por largura de pulso: uma onda quadrada cuja fração do tempo em nível alto controla brilho, posição de servo ou potência. (cap. 7)
    duty (ciclo de trabalho) a fração do período em que o sinal PWM fica em nível alto, em passos de 0 a 2bits. (cap. 7)
    Adapter padrão em que uma classe converte a interface de uma peça (0 a 4095, duty) na interface que o programa espera (graus, permil). (cap. 7)
    sensor inteligente um sensor que entrega a grandeza já calibrada, com unidade, faixa e validade, e não o número cru do conversor. (cap. 7)
    calibração os números que ligam a leitura crua de um sensor (ou o comando de um atuador) à grandeza real, como dois pontos medidos ou os extremos de pulso de um servo. (cap. 7)
    interpolação linear estimar um valor entre dois pontos conhecidos de uma tabela pela reta que os liga. (cap. 7)
    interface uma classe abstrata (só métodos virtual ... = 0) que diz o que uma peça faz, sem dizer como: ISensor, ISaida, IRelogio. (cap. 8)
    override marca o método de uma classe filha que substitui um virtual da base; o compilador confere que a substituição existe. (cap. 8)
    tabela de métodos virtuais a tabela, uma por classe, que a chamada virtual consulta; cada objeto guarda um ponteiro para ela (4 bytes no ESP32). (cap. 8)
    injeção de dependência entregar a um objeto, pelo construtor, as peças de que ele precisa, em vez de ele ir buscá-las (millis(), um pino fixo). (cap. 8)
    raiz de composição o único lugar que cria as peças de verdade e as entrega à lógica; no curso, os objetos globais do sketch.ino. (cap. 8)
    HAL Hardware Abstraction Layer: o conjunto de interfaces que isola a lógica do hardware. (cap. 8)
    dublê de teste o que substitui uma dependência num teste: stub (devolve o programado), fake (funciona, simplificado), spy (anota o que lhe fizeram), mock (confere a expectativa). (cap. 8)
    seam o ponto onde se troca o real pelo dublê sem editar o código testado: um arquivo incluído (link seam) ou um objeto injetado (interface seam). (cap. 8)
    TDD Test-Driven Development: escrever o teste antes, vê-lo falhar, escrever o mínimo para passar, e então limpar. (cap. 8)
    Decorator padrão em que uma classe embrulha outra de mesma interface para acrescentar um comportamento (registrar, medir) sem mudá-la. (cap. 8)
    relé uma chave comandada por um sinal fraco, que liga e desliga uma carga de potência (bomba, motor, lâmpada). (cap. 8)

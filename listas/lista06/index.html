    Lista 06 · volatile e Hardware Proxy¶

    Exercícios do capítulo 6 — volatile e Hardware Proxy.

    Nos exercícios de computador, os registradores são variáveis volatile uint32_t que o teste cria e depois examina: elas guardam a última escrita, e é isso que os testes conferem. O tempo em microssegundos anda com falso::avanca_micros(us) (e falso::avanca_tempo(ms) continua andando em milissegundos). Nos exercícios do Wokwi, o mesmo código escreve nos endereços de verdade do ESP32.

    Como resolver

    Exercícios ex (sem placa): copie o bloco de código, cole no seu compilador online, preencha a parte marcada como ESCREVA SUA SOLUCAO AQUI e rode. A saída mostra quais testes passaram.

    Exercícios wk (no Wokwi): monte o projeto inicial no Wokwi, complete o código e confira o resultado contra o critério de pronto do enunciado.

    falso::reinicia();
    volatile uint32_t w1ts = 0, w1tc = 0, in = 0;
    BancoGpio gpio0{w1ts, w1tc, in};
    LedRapido led(gpio0, 26);

    led.inicia();
    assert(falso::modo(26) == OUTPUT);
    assert(w1tc == (1u << 26));            // inicia() desliga
    assert(!led.esta_ligado());

    // = e nao |=: o valor que estava la antes nao pode sobrar
    w1ts = 0xFFFF;
    led.liga();
    assert(w1ts == (1u << 26));
    assert(led.esta_ligado());

    w1tc = 0xFFFF;
    led.desliga();
    assert(w1tc == (1u << 26));
    assert(!led.esta_ligado());

    // alterna usa liga/desliga
    w1ts = 0;
    w1tc = 0;
    led.alterna();
    assert(led.esta_ligado());
    assert(w1ts == (1u << 26) && w1tc == 0);
    led.alterna();
    assert(!led.esta_ligado());
    assert(w1tc == (1u << 26));

    // o Proxy nao usa digitalWrite: o pino 26 do Arduino falso nunca foi escrito
    assert(falso::escritas(26) == 0);

    // pino do banco 1: 33 e o bit 1
    w1ts = 0;
    volatile uint32_t w1ts1 = 0, w1tc1 = 0, in1 = 0;
    BancoGpio gpio1{w1ts1, w1tc1, in1};
    LedRapido outro(gpio1, 33);
    outro.inicia();
    outro.liga();
    assert(w1ts1 == 0x2);
    assert(w1ts == 0);                     // o banco 0 nao foi tocado

    std::cout << "Todos os testes passaram!\n";
    return 0;
}

    ex03¶

    Uma vantagem dos registradores sobre o digitalWrite: mudar vários pinos no mesmo instante, numa escrita só. O GrupoDeLeds controla três LEDs do mesmo banco e mostra um número de 3 bits: o bit 0 do número vai para o primeiro LED, o bit 1 para o segundo, o bit 2 para o terceiro.

    Complete:

    • o construtor, que monta mascara_total_ (os bits dos três pinos);
    • mostra(valor): faz uma escrita no W1TC com os pinos que devem apagar e uma escrita no W1TS com os que devem acender. Só os 3 bits de baixo de valor contam.
    GrupoDeLeds barra(gpio0, 25, 26, 27);   // bit 0 -> 25, bit 1 -> 26, bit 2 -> 27
barra.mostra(0b101);    // acende 25 e 27, apaga 26
w1ts;                   // -> (1<<25) | (1<<27)
w1tc;                   // -> (1<<26)

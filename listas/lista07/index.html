    Lista 07 · ADC e PWM atrás de um Adapter¶

    Exercícios do capítulo 7 — ADC e PWM atrás de um Adapter.

    Nos exercícios de computador, o ADC é o do Arduino falso: o teste põe uma leitura no pino com falso::poe_analogico(pino, bruto) (0 a 4095), e o analogRead devolve esse número. O PWM falso guarda o que a classe pediu: falso::frequencia(pino), falso::bits_pwm(pino) e falso::duty(pino). Toda conta é inteira: nenhum exercício usa float.

    Como resolver

    Exercícios ex (sem placa): copie o bloco de código, cole no seu compilador online, preencha a parte marcada como ESCREVA SUA SOLUCAO AQUI e rode. A saída mostra quais testes passaram.

    Exercícios wk (no Wokwi): monte o projeto inicial no Wokwi, complete o código e confira o resultado contra o critério de pronto do enunciado.

    ex01¶

    Complete escala(), a função que leva um número de uma faixa para outra. Ela precisa:

    1. saturar: abaixo de de_min devolve para_min; acima de de_max devolve para_max;
    2. arredondar para o inteiro mais próximo (somar metade do denominador antes de dividir);
    3. funcionar com faixa de saída invertida (para_min > para_max), em que o numerador fica negativo;
    4. fazer a conta do meio em 64 bits, porque o produto passa de 2³¹.
    escala(2048, 0, 4095, 0, 1000);    // -> 500
escala(4200, 0, 4095, 0, 1000);    // -> 1000   (saturou)
escala(333, 0, 1000, 180, 0);      // -> 120    (o map() do Arduino daria 121)
escala(40000, 0, 65535, 0, 60000); // -> 36622

    Pode supor sempre de_min < de_max.

    ex02¶

    Um sensor de nível de caixa d'água foi calibrado em dois pontos: com a caixa vazia, o ADC leu 410 (0 mm); com a caixa cheia, leu 3690 (2000 mm). Entre os dois, o sensor é linear.

    Complete a classe Calibracao, que guarda os dois pontos e converte qualquer leitura numa grandeza:

    • converte(bruto) passa pela reta que liga os dois pontos, arredondando para o inteiro mais próximo;
    • ela não satura: uma leitura além dos pontos calibrados é extrapolada (decidir o que fazer com ela é trabalho de quem usa a calibração, como no exercício 4);

    Calibracao nivel(410, 0, 3690, 2000);
nivel.converte(410);     // -> 0
nivel.converte(2050);    // -> 1000
nivel.converte(4095);    // -> 2247   (extrapolado)

    ex03¶

    Complete interpola(), que transforma uma leitura bruta numa grandeza usando uma tabela de pontos, como a do NTC no capítulo. A tabela está em ordem de bruto decrescente (como a do NTC: mais quente, leitura menor).

    • Se bruto cai entre dois pontos vizinhos, a resposta é a reta entre eles, arredondada, e a leitura é válida.
    • Se bruto cai exatamente num ponto, a resposta é o valor desse ponto.
    • Fora da tabela (acima do primeiro ou abaixo do último ponto), a leitura é inválida (o valor não importa).
    const Ponto tabela[] = {{1000, 0}, {500, 100}, {0, 300}};
interpola(tabela, 3, 750);     // -> {50, true}
interpola(tabela, 3, 333);     // -> {167, true}
interpola(tabela, 3, 1001);    // -> {?, false}

#include <iostream>
#include <cstdint>

// ============================================================
// NAO ALTERE — Arduino de mentira (no Wokwi, use #include <Arduino.h>)
// ============================================================
// arduino_falso.h -- um <Arduino.h> de mentira, para rodar no computador (ou num
// compilador online) o mesmo codigo de classe que roda no ESP32 do Wokwi.
//
// Nao e um simulador. E so o suficiente para:
//   * o compilador aceitar pinMode/digitalWrite/digitalRead/millis/micros/Serial,
//     analogRead e o PWM do ESP32 (ledcAttach/ledcWrite/ledcWriteTone);
//   * os testes perguntarem "o que a classe fez com o pino?" e "o que ela
//     faria se o tempo andasse 500 ms?".
//
// Como funciona: cada pino guarda o ultimo nivel escrito e o ultimo modo
// configurado; millis() e micros() leem um relogio que so anda quando o teste
// manda (falso::avanca_tempo em ms, falso::avanca_micros em us). digitalRead devolve o que o teste pos no pino com
// falso::poe_nivel -- e assim que se "aperta um botao" sem botao. analogRead devolve
// o que o teste pos com falso::poe_analogico, e o PWM guarda frequencia, bits e duty.
//
// No Wokwi, troque  #include "arduino_falso.h"  por  #include <Arduino.h>
// e o resto do codigo continua igual.
#ifndef ARDUINO_FALSO_H
#define ARDUINO_FALSO_H

// ---- Constantes com os mesmos nomes do Arduino ----------------------------
const int LOW = 0;
const int HIGH = 1;

const int INPUT = 0;
const int OUTPUT = 1;
const int INPUT_PULLUP = 2;

// Atenuacao do ADC, com os nomes do core 3.x (o padrao do chip e ADC_11db).
enum adc_attenuation_t { ADC_0db, ADC_2_5db, ADC_6db, ADC_11db, ADC_ATTENDB_MAX };

// ---- Estado do "hardware" falso -------------------------------------------
namespace falso {

const int NUM_PINOS = 40;   // o ESP32 tem GPIO 0 a 39

struct Pino {
    int nivel = LOW;
    int modo = -1;          // -1: ninguem chamou pinMode ainda
    int escritas = 0;       // quantas vezes digitalWrite foi chamado neste pino
    int analogico = 0;      // o que analogRead devolve (0 a 4095, como o ADC de 12 bits)
    int atenuacao = -1;     // -1: ninguem chamou analogSetPinAttenuation
    bool pwm = false;       // ledcAttach foi chamado?
    uint32_t pwm_freq = 0;  // Hz
    int pwm_bits = 0;       // resolucao do duty
    uint32_t pwm_duty = 0;  // ultimo valor de ledcWrite
};

inline Pino& pino(int numero) {
    static Pino pinos[NUM_PINOS];
    return pinos[numero % NUM_PINOS];
}

// O relogio guarda MICROSSEGUNDOS; millis() e so ele dividido por 1000.
inline unsigned long long& relogio_us() {
    static unsigned long long agora_us = 0;
    return agora_us;
}

// Para os testes: espiar e mexer no mundo externo.
inline int nivel(int numero) { return pino(numero).nivel; }
inline int modo(int numero) { return pino(numero).modo; }
inline int escritas(int numero) { return pino(numero).escritas; }
inline void poe_nivel(int numero, int nivel) { pino(numero).nivel = nivel; }
inline void poe_analogico(int numero, int bruto) { pino(numero).analogico = bruto; }
inline int atenuacao(int numero) { return pino(numero).atenuacao; }
inline bool pwm(int numero) { return pino(numero).pwm; }
inline uint32_t frequencia(int numero) { return pino(numero).pwm_freq; }
inline int bits_pwm(int numero) { return pino(numero).pwm_bits; }
inline uint32_t duty(int numero) { return pino(numero).pwm_duty; }
inline void avanca_tempo(unsigned long ms) { relogio_us() += 1000ull * ms; }
inline void avanca_micros(unsigned long us) { relogio_us() += us; }

// Volta tudo ao estado de "placa recem-ligada".
inline void reinicia() {
    for (int i = 0; i < NUM_PINOS; i++) {
        pino(i) = Pino{};
    }
    relogio_us() = 0;
}

}  // namespace falso

// ---- As funcoes do Arduino --------------------------------------------------
inline void pinMode(int numero, int modo) {
    falso::pino(numero).modo = modo;
    // Com pull-up interno, um pino de entrada solto le HIGH -- igual ao real.
    if (modo == INPUT_PULLUP) {
        falso::pino(numero).nivel = HIGH;
    }
}

inline void digitalWrite(int numero, int nivel) {
    falso::pino(numero).nivel = nivel;
    falso::pino(numero).escritas++;
}

inline int digitalRead(int numero) {
    return falso::pino(numero).nivel;
}

// Como no ESP32, os dois sao de 32 bits e dao a volta (millis em ~49 dias,
// micros em ~71 minutos).
inline unsigned long millis() {
    return static_cast<uint32_t>(falso::relogio_us() / 1000);
}

inline unsigned long micros() {
    return static_cast<uint32_t>(falso::relogio_us());
}

inline void delay(unsigned long ms) {
    falso::relogio_us() += 1000ull * ms;
}

inline void delayMicroseconds(unsigned int us) {
    falso::relogio_us() += us;
}

// ---- ADC e PWM (LEDC) do ESP32, com as assinaturas do core 3.x -------------
inline void analogSetPinAttenuation(int numero, adc_attenuation_t atenuacao) {
    falso::pino(numero).atenuacao = atenuacao;
}

inline uint16_t analogRead(int numero) {
    return static_cast<uint16_t>(falso::pino(numero).analogico);
}

inline bool ledcAttach(int numero, uint32_t freq, uint8_t bits) {
    falso::Pino& p = falso::pino(numero);
    p.pwm = true;
    p.pwm_freq = freq;
    p.pwm_bits = bits;
    p.pwm_duty = 0;
    return true;
}

inline bool ledcWrite(int numero, uint32_t duty) {
    falso::Pino& p = falso::pino(numero);
    if (!p.pwm) {
        return false;   // como no real: sem ledcAttach, nada acontece
    }
    p.pwm_duty = duty;
    return true;
}

// Como no core 3.x: frequencia 0 so zera o duty; senao o pino passa a 10 bits
// e duty 0x1FF (quase 50%), uma onda quadrada na frequencia pedida.
inline uint32_t ledcWriteTone(int numero, uint32_t freq) {
    falso::Pino& p = falso::pino(numero);
    if (!p.pwm) {
        return 0;
    }
    if (freq == 0) {
        p.pwm_duty = 0;
        return 0;
    }
    p.pwm_freq = freq;
    p.pwm_bits = 10;
    p.pwm_duty = 0x1FF;
    return freq;
}

#ifndef EX04_H
#define EX04_H

struct Leitura {

// Calibracao de dois pontos (o exercicio 2, pronto).
class Calibracao {
private:
    const int32_t bruto_a_;
    const int32_t valor_a_;
    const int32_t bruto_b_;
    const int32_t valor_b_;

public:
    Calibracao(int32_t bruto_a, int32_t valor_a, int32_t bruto_b, int32_t valor_b)
        : bruto_a_(bruto_a), valor_a_(valor_a), bruto_b_(bruto_b), valor_b_(valor_b) {}

    int32_t converte(int32_t bruto) const {
        int64_t num = static_cast<int64_t>(bruto - bruto_a_) * (valor_b_ - valor_a_);
        int64_t den = bruto_b_ - bruto_a_;
        if (den < 0) {
            num = -num;
            den = -den;
        }
        int64_t meio = (num >= 0) ? den / 2 : -den / 2;
        return valor_a_ + static_cast<int32_t>((num + meio) / den);
    }
};

    static const int32_t BRUTO_FIO_SOLTO = 200;    // abaixo disso: invalida

inline int32_t escala(int32_t x, int32_t de_min, int32_t de_max, int32_t para_min, int32_t para_max) {
    if (x <= de_min) {

// para o inteiro mais proximo e saturando fora da faixa de entrada.

                         int32_t para_min, int32_t para_max) {

        return para_min;

        return para_max;

    wk02 · no Wokwi¶

    O termômetro sem números mágicos. O sketch.ino inicial é o termômetro do começo do capítulo: o NTC move o servo e o buzzer apita acima de 76 °C, mas toda conta está no loop(). Os Adapters do capítulo já estão nos arquivos .h. Reescreva o sketch.ino com eles:

    • um using Sensor = SensorNtc; e um objeto Sensor sensor(35);, um ServoMotor no 13 e um Buzzer no 14;
    • o loop() só pode usar le(), minimo(), maximo() e unidade() do sensor: o ponteiro percorre a faixa do sensor de 0 a 180 graus, e o alarme toca 880 Hz a partir de 80% da faixa;
    • leitura inválida: o alarme fica quieto e o Serial imprime leitura invalida;
    • uma vez por segundo, o Serial imprime o valor e a unidade (251 decimos de C).

    Depois, troque o sensor: mude só a linha do using e a do objeto para usar o Potenciometro no pino 34, e rode de novo.

    Para mudar a temperatura, clique no NTC na bancada e arraste o controle (ele vai de −24 °C a 80 °C).

    Critério de pronto:

    1. Com o NTC a 25 °C, o Serial mostra 251 decimos de C e o servo aponta perto de 68 graus.
    2. Com o NTC acima de 76 °C, o buzzer toca; abaixo, para.
    3. Com o NTC abaixo de −20 °C, o Serial mostra leitura invalida e o buzzer não toca.
    4. Trocado para o potenciômetro (duas linhas), com ele no meio do curso, o Serial mostra cerca de 500 permil e o servo vai a 90 graus, sem nenhuma outra mudança no loop().
    5. O loop() não tem nenhum número que pertença a uma peça (4095, 3950, 446...).

    Projeto inicial — crie um projeto ESP32 no Wokwi e cole cada aba no arquivo de mesmo nome (veja como montar o projeto).

    // Lista 07 - wk02: reescreva este loop() com os Adapters dos arquivos .h.
// Hoje ele funciona, mas cada numero pertence a uma peca: 4095 ao ADC,
// 10000 e 3950 ao NTC, 446 e 1966 ao servo, 76 ao limiar em graus.
#include <math.h>
#include "sensor_ntc.h"
#include "potenciometro.h"
#include "atuadores.h"
#include "temporizador.h"

Temporizador um_segundo(1000);

void setup() {
    Serial.begin(115200);
    ledcAttach(13, 50, 14);
    ledcAttach(14, 1000, 10);
    um_segundo.reinicia();
    Serial.println("termometro de ponteiro");
}

void loop() {
    int bruto = analogRead(35);
    float r = 10000.0 * bruto / (4095 - bruto);
    float c = 1 / (log(r / 10000) / 3950 + 1 / 298.15) - 273.15;
    ledcWrite(13, map(c, -20, 100, 446, 1966));
    if (c > 76) {
        ledcWriteTone(14, 880);
    } else {
        ledcWriteTone(14, 0);
    }
    if (um_segundo.expirou()) {
        Serial.println(c);
    }
}

    // atuadores.h -- Adapters de saida sobre o PWM (LEDC) do ESP32.
#ifndef ATUADORES_H
#define ATUADORES_H

#include <Arduino.h>
#include "escala.h"

// Brilho de um LED (ou qualquer carga) em permil: 0 apagado, 1000 aceso.
class SaidaPwm {
private:
    const int pino_;
    const uint32_t freq_hz_;
    const uint8_t bits_;

public:
    SaidaPwm(int pino, uint32_t freq_hz, uint8_t bits)
        : pino_(pino), freq_hz_(freq_hz), bits_(bits) {}

    void inicia() { ledcAttach(pino_, freq_hz_, bits_); }

    void escreve_permil(int32_t permil) {
        int32_t maximo = (1 << bits_) - 1;
        ledcWrite(pino_, escala(permil, 0, 1000, 0, maximo));
    }
};

// Servo de hobby: um pulso a cada 20 ms; a largura do pulso diz o angulo.
// 544 e 2400 us sao os extremos do Wokwi (e do Servo do Arduino); servos
// reais variam, por isso os extremos sao configuraveis: e a calibracao.
class ServoMotor {
private:
    const int pino_;
    const int32_t pulso_min_us_;
    const int32_t pulso_max_us_;

    static const uint32_t FREQ_HZ = 50;      // periodo de 20 ms
    static const uint8_t BITS = 14;          // 20000 us viram 16384 passos
    static const int32_t PERIODO_US = 20000;

public:
    explicit ServoMotor(int pino, int32_t pulso_min_us = 544, int32_t pulso_max_us = 2400)
        : pino_(pino), pulso_min_us_(pulso_min_us), pulso_max_us_(pulso_max_us) {}

    void inicia() { ledcAttach(pino_, FREQ_HZ, BITS); }

    // 0 a 180 graus; fora disso, satura no batente.
    void vai_para(int32_t graus) {
        int32_t pulso_us = escala(graus, 0, 180, pulso_min_us_, pulso_max_us_);
        ledcWrite(pino_, escala(pulso_us, 0, PERIODO_US, 0, 1 << BITS));
    }
};

// Buzzer passivo: uma onda quadrada na frequencia pedida.
class Buzzer {
private:
    const int pino_;
    uint32_t tocando_hz_;    // 0: em silencio

public:
    explicit Buzzer(int pino) : pino_(pino), tocando_hz_(0) {}

    void inicia() { ledcAttach(pino_, 1000, 10); silencia(); }

    void toca(uint32_t freq_hz) {
        if (freq_hz != tocando_hz_) {    // reconfigurar o timer a cada volta faria clique
            ledcWriteTone(pino_, freq_hz);
            tocando_hz_ = freq_hz;
        }
    }

    void silencia() { toca(0); }

    bool tocando() const { return tocando_hz_ != 0; }
};

    // escala.h -- levar um numero de uma faixa para outra so com inteiros.
#ifndef ESCALA_H
#define ESCALA_H

#include <stdint.h>

// Leva x da faixa [de_min, de_max] para [para_min, para_max], arredondando
// para o inteiro mais proximo e saturando fora da faixa de entrada.
// (O map() do Arduino trunca e nao satura.) A conta e feita em 64 bits porque
// o produto do meio passa de 2^31 com facilidade.
constexpr int32_t escala(int32_t x, int32_t de_min, int32_t de_max,
                         int32_t para_min, int32_t para_max) {
    if (x <= de_min) {
        return para_min;
    }
    if (x >= de_max) {
        return para_max;
    }
    int64_t num = static_cast<int64_t>(x - de_min) * (para_max - para_min);
    int64_t den = de_max - de_min;
    int64_t meio = (num >= 0) ? den / 2 : -den / 2;
    return para_min + static_cast<int32_t>((num + meio) / den);
}

#endif

    // sensor_ntc.h -- Adapter: do ADC (0 a 4095) para temperatura em decimos de grau.
#ifndef SENSOR_NTC_H
#define SENSOR_NTC_H

#include <Arduino.h>
#include "leitura.h"

struct PontoNtc {
    int32_t bruto;       // leitura do ADC
    int32_t decimos_c;   // temperatura nessa leitura, em decimos de grau
};

// Modulo NTC do Wokwi: 10 kOhm (3,3 V -> saida) + NTC 10 kOhm, beta 3950
// (saida -> GND). Mais quente, leitura menor. Gerado por
// exemplos/cap07_tabela_ntc.cpp; pior erro da interpolacao: 0,52 C.
const PontoNtc TABELA_NTC[] = {
    {3740,  -200},
    {3495,  -100},
    {3156,     0},
    {2738,   100},
    {2278,   200},
    {1825,   300},
    {1419,   400},
    {1081,   500},
    { 815,   600},
    { 613,   700},
    { 462,   800},
    { 350,   900},
    { 267,  1000},
};
const int PONTOS_NTC = sizeof(TABELA_NTC) / sizeof(TABELA_NTC[0]);

// Interpolacao linear entre os dois pontos vizinhos, so com inteiros.
// Fora da tabela (frio demais, quente demais, fio solto ou em curto): invalida.
inline Leitura ntc_para_decimos(int32_t bruto) {
    for (int i = 0; i + 1 < PONTOS_NTC; i++) {
        const PontoNtc& a = TABELA_NTC[i];
        const PontoNtc& b = TABELA_NTC[i + 1];
        if (bruto <= a.bruto && bruto >= b.bruto) {
            int32_t num = (a.bruto - bruto) * (b.decimos_c - a.decimos_c);
            int32_t den = a.bruto - b.bruto;
            return {a.decimos_c + (num + den / 2) / den, true};
        }
    }
    return {0, false};
}

class SensorNtc {
private:
    const int pino_;

public:
    explicit SensorNtc(int pino) : pino_(pino) {}

    void inicia() { analogSetPinAttenuation(pino_, ADC_11db); }

    Leitura le() const { return ntc_para_decimos(analogRead(pino_)); }

    int32_t minimo() const { return TABELA_NTC[0].decimos_c; }
    int32_t maximo() const { return TABELA_NTC[PONTOS_NTC - 1].decimos_c; }
    const char* unidade() const { return "decimos de C"; }
};

#endif

    // temporizador.h -- a classe Temporizador do capitulo 3.
#ifndef TEMPORIZADOR_H
#define TEMPORIZADOR_H

#include <Arduino.h>

// Avisa, sem travar o programa, que um intervalo de tempo passou.
// Periodico: depois de avisar, comeca a contar o proximo intervalo sozinho.
class Temporizador {
private:
    unsigned long intervalo_ms_;
    unsigned long inicio_ms_;

public:
    explicit Temporizador(unsigned long intervalo_ms)
        : intervalo_ms_(intervalo_ms), inicio_ms_(0) {}

    // Comeca a contar a partir de agora.
    void reinicia() {
        inicio_ms_ = millis();
    }

    // true uma vez a cada intervalo. Chame a cada volta do loop().
    bool expirou() {
        unsigned long agora = millis();
        if (agora - inicio_ms_ >= intervalo_ms_) {
            inicio_ms_ = agora;
            return true;
        }
        return false;
    }
};

#endif

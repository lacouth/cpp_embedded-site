    Lista 05 · Bits em C++ e registradores tipados¶

    Exercícios do capítulo 5 — Bits em C++ e registradores tipados.

    Esta lista é toda de computador: o "registrador" é uma variável uint32_t. Escreva as contas com 1u (nunca 1), e lembre que gravar um campo é limpar e depois colocar. Quando um teste falhar, imprima o valor em hexadecimal (std::cout << std::hex << valor) e compare bit a bit com o esperado.

    Como resolver

    Exercícios ex (sem placa): copie o bloco de código, cole no seu compilador online, preencha a parte marcada como ESCREVA SUA SOLUCAO AQUI e rode. A saída mostra quais testes passaram.

    Exercícios wk (no Wokwi): monte o projeto inicial no Wokwi, complete o código e confira o resultado contra o critério de pronto do enunciado.

    ex01¶

    Escreva as quatro operações de bit como funções que recebem um valor de 32 bits e devolvem o valor modificado (sem mexer em nenhum outro bit):

    • liga_bit(v, n): o bit n passa a valer 1;
    • desliga_bit(v, n): o bit n passa a valer 0;
    • inverte_bit(v, n): o bit n troca de valor;
    • testa_bit(v, n): true se o bit n vale 1.
    liga_bit(0x00, 3);          // -> 0x08
desliga_bit(0xFF, 0);       // -> 0xFE
inverte_bit(0x0F, 7);       // -> 0x8F
testa_bit(0x80000000u, 31); // -> true

    ex02¶

    Duas perguntas comuns sobre os bits de um valor:

    • conta_bits_ligados(v): quantos bits valem 1 (útil, por exemplo, para saber quantos LEDs de uma barra estão acesos);
    • eh_potencia_de_dois(v): true se exatamente um bit está ligado (1, 2, 4, 8, …). Zero não é potência de dois.

    Use só operações de bit e laços: nada de <cmath>.

    conta_bits_ligados(0b1011);     // -> 3
conta_bits_ligados(0xFFFFFFFFu); // -> 32
eh_potencia_de_dois(64);        // -> true
eh_potencia_de_dois(6);         // -> false

    Desafio (sem teste): v & (v - 1) desliga o bit ligado mais baixo de v. Dá para escrever eh_potencia_de_dois numa linha só com isso.

    ex03¶

    Escreva as três funções de campo do capítulo:

    • mascara(largura): largura bits ligados a partir do bit 0. Cuidado com largura == 32: deslocar 32 posições não é permitido;
    • extrai_campo(valor, pos, largura): o número guardado nos bits pos a pos + largura - 1;
    • grava_campo(valor, pos, largura, novo): devolve valor com o campo trocado por novo. Os outros bits não mudam, e se novo não couber no campo, os bits que sobram são descartados (não invadem o campo vizinho).
    mascara(4);                              // -> 0xF
extrai_campo(0x0000'0A00, 8, 8);         // -> 0x0A
grava_campo(0x0000'0301, 8, 8, 4);       // -> 0x0000'0401
grava_campo(0x0000'0301, 8, 8, 0x1FF);   // -> 0x0000'FF01

    ex04¶

    Displays pequenos (como o que aparece no capítulo 17) guardam cada pixel em 16 bits, no formato RGB565: 5 bits de vermelho, 6 de verde, 5 de azul.

     15     11 10       5 4      0
┌─────────┬──────────┬────────┐
│ vermelho│  verde   │  azul  │
└─────────┴──────────┴────────┘

    As cores chegam com 8 bits por componente (0 a 255). Para caber, fica só a parte mais significativa de cada uma: os 5 bits de cima do vermelho e do azul, os 6 de cima do verde.

    • rgb565(r, g, b): monta o pixel;
    • vermelho565(p), verde565(p), azul565(p): devolvem o campo de cada cor como está no pixel (0 a 31, 0 a 63, 0 a 31).
    rgb565(255, 0, 0);       // -> 0xF800
rgb565(0, 255, 0);       // -> 0x07E0
rgb565(0, 0, 255);       // -> 0x001F
verde565(0x07E0);        // -> 63

    ex05¶

    Complete os quatro métodos de bit do Registrador32. A classe guarda uma referência para a palavra de 32 bits: o que o método faz tem que aparecer na variável de fora.

#include <cstdint>

// ============================================================
// Declaracoes do exercicio
// ============================================================
#ifndef EX05_H
#define EX05_H

inline uint32_t mascara(unsigned largura) {
    return largura >= 32 ? 0xFFFFFFFFu : (1u << largura) - 1u;
}

// Um registrador de 32 bits visto por metodos com nome.
// Guarda uma REFERENCIA: mexe na variavel de fora, nao numa copia.
class Registrador32 {
private:
    uint32_t& valor_;

public:
    explicit Registrador32(uint32_t& valor) : valor_(valor) {}

    void liga(unsigned bit);
    void desliga(unsigned bit);
    void inverte(unsigned bit);
    bool testa(unsigned bit) const;

        return (valor_ >> pos) & mascara(largura);

        uint32_t m = mascara(largura) << pos;
        valor_ = (valor_ & ~m) | ((novo << pos) & m);

    ex06¶

    Um canal de PWM (fictício) é controlado por um registrador de 32 bits:

     31               16 15     8 7       4 3   2    1        0
┌───────────────────┬────────┬─────────┬───────┬────────┬─────┐
│       DUTY        │ (res.) │RESOLUCAO│ (res.)│POLARID.│LIGA │
└───────────────────┴────────┴─────────┴───────┴────────┴─────┘
    • LIGA (bit 0): o canal gera o sinal;
    • POLARIDADE (bit 1): 0 normal, 1 invertida;
    • RESOLUCAO (bits 4–7): quantos bits tem o duty, de 1 a 15;
    • DUTY (bits 16–31): o tempo ligado, de 0 até 2^resolucao - 1.

    Complete a ConfigPwm sobre o Registrador32 (pronto). Ela protege dois invariantes, como as classes do capítulo 2:

    • ajusta_resolucao(bits) ignora valores fora de 1 a 15 (o registrador não muda);
    • ajusta_duty(d) satura: se d passar do máximo da resolução atual, grava o máximo. E ao diminuir a resolução, um duty que deixou de caber é saturado também.
    uint32_t r = 0;
ConfigPwm pwm(r);
pwm.ajusta_resolucao(8);
pwm.ajusta_duty(1000);       // satura em 255
pwm.duty();                  // -> 255
pwm.ajusta_polaridade(Polaridade::Invertida);
pwm.liga();
r;                           // -> 0x00FF0083

int main() {
    uint32_t r = 0;
    ConfigPwm pwm(r);

    // liga/desliga mexe so no bit 0
    pwm.liga();
    assert(pwm.ligado());
    assert(r == 0x1);
    pwm.desliga();
    assert(!pwm.ligado());
    assert(r == 0x0);

    // polaridade no bit 1
    pwm.ajusta_polaridade(Polaridade::Invertida);
    assert(r == 0x2);
    assert(pwm.polaridade() == Polaridade::Invertida);
    pwm.ajusta_polaridade(Polaridade::Normal);
    assert(r == 0x0);
    assert(pwm.polaridade() == Polaridade::Normal);

    // resolucao nos bits 4-7, so de 1 a 15
    pwm.ajusta_resolucao(8);
    assert(pwm.resolucao() == 8);
    assert(r == 0x80);
    assert(pwm.duty_maximo() == 255);
    pwm.ajusta_resolucao(0);                 // ignorado
    pwm.ajusta_resolucao(16);                // ignorado
    assert(pwm.resolucao() == 8);
    assert(r == 0x80);

    // duty nos bits 16-31, saturado
    pwm.ajusta_duty(100);
    assert(pwm.duty() == 100);
    assert(r == 0x00640080u);
    pwm.ajusta_duty(1000);
    assert(pwm.duty() == 255);

    // o exemplo do enunciado
    pwm.ajusta_polaridade(Polaridade::Invertida);
    pwm.liga();
    assert(r == 0x00FF0083u);

    // diminuir a resolucao satura o duty que deixou de caber
    pwm.ajusta_resolucao(4);
    assert(pwm.duty_maximo() == 15);
    assert(pwm.duty() == 15);
    assert(pwm.ligado());                    // o resto nao mudou
    assert(pwm.polaridade() == Polaridade::Invertida);

    // aumentar a resolucao nao mexe no duty
    pwm.ajusta_resolucao(15);
    assert(pwm.duty() == 15);
    assert(pwm.duty_maximo() == 32767);
    pwm.ajusta_duty(40000);
    assert(pwm.duty() == 32767);
    assert(r == 0x7FFF00F3u);

    std::cout << "Todos os testes passaram!\n";
    return 0;
}
